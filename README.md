# alontito-web — ЭТО ФРОНТЕНД (то, что видит пользователь)

**Автор: R_stepanov**

Если `messenger-server` — это "мозги и память" (сервер, база данных), то
это — сам экран телефона, кнопки, чат. Отдельно от бэкенда, заливается
на **другой** хостинг (Netlify/Vercel — для статичных сайтов), а не на
Render (тот — для messenger-server).

## Карта: что куда

| Что | Где лежит | Куда заливать | Зачем |
|---|---|---|---|
| Бэкенд (сервер, база, шифрование) | папка `messenger-server` (отдельный архив) | **Render.com** | работает в фоне 24/7 |
| Фронтенд (то, что видит юзер) | эта папка `alontito-web` | **Netlify** или **Vercel** | сам сайт/приложение |

Это **два разных архива, два разных хостинга**. Спутать их — частая
причина путаницы: если закинуть `alontito-web` на Render или наоборот
`messenger-server` на Netlify — работать не будет, это разные типы
хостинга под разные типы кода.

## Порядок действий (сделать один раз)

### Шаг 1 — бэкенд

Задеплой `messenger-server` на Render (см. его README). Получишь адрес
вида `https://alontito-backend.onrender.com` — это и есть "твой сервер".
Не забудь там же в Render прописать переменную `ANTHROPIC_API_KEY` (ключ
Claude, чтобы AI-агент отвечал) и `FRONTEND_ORIGIN` (впишешь после шага 3).

### Шаг 2 — впиши адрес сервера в код фронтенда

Открой `src/App.jsx`, самое начало файла:

```js
const API_URL = "https://ЗАМЕНИ-НА-СВОЙ-СЕРВЕР.onrender.com";
```

Замени на реальный адрес из шага 1.

### Шаг 3 — собери и залей фронтенд

```bash
npm install
npm run build
```

Появится папка `dist/` — вот её и заливаешь:

**Netlify (проще всего, без консоли):**
1. netlify.com → зарегистрируйся
2. Перетащи папку `dist` в браузер на их главной странице ("Deploy manually")
3. Получишь ссылку вида `https://alontito.netlify.app`

Вернись в Render, впиши эту ссылку в `FRONTEND_ORIGIN` бэкенда и
перезапусти сервис (Render сделает это сам после сохранения переменной).

### Шаг 4 — установи на телефон

Открой ссылку из шага 3 на телефоне → в Chrome/Safari выбери "Добавить
на экран Домой" — появится иконка Alontito со смайликом, открывается на
весь экран как обычное приложение.

## Что нового в этой версии

- **AI-агент работает** — теперь стучится не напрямую в Claude API (это
  блокировалось бы CORS вне Claude.ai), а через `/api/ai/complete` на
  твоём же сервере — ключ Claude там и остаётся, в браузер не попадает
- **Отправка фото** — кнопка со значком картинки рядом с полем ввода;
  фото автоматически сжимается на телефоне перед отправкой, чтобы не
  раздувать базу и не грузить канал
- **Титулы за время в приложении** — 6 уровней (от "Новичок эфира" до
  "Владыка Alontito"), вращающееся градиентное кольцо вокруг аватарки,
  прогресс-бар до следующего уровня. Считается по реальному времени с
  открытой вкладкой (раз в 30 сек шлётся на сервер)
- **Закреплённые чаты** — кнопка-булавка при наведении на чат в списке,
  закреплённые всегда сверху
- **Закреплённые сообщения** — кнопка-булавка на сообщении, баннер
  закреплённых вверху диалога, синхронизируется у обоих собеседников
  живьём через WebSocket
- **Простой вход** — токен сохраняется в браузере, при повторном
  открытии не нужно заново вводить код (если сессия ещё не истекла)
- **Хранилище "Данные"** — отдельный раздел с усиленной защитой (свой
  пароль + свежий SMS-код при каждом входе), подробности в README
  `messenger-server`
- **Автор в профиле** — внизу панели профиля подпись "Alontito · автор
  R_stepanov"
- Все доработки безопасности (rate-limit, лимит попыток кода,
  шифрование) — на стороне `messenger-server`, см. его README

## Если решишь потом обновить код

Поменял что-то → `npm run build` → залил новую `dist` на тот же
Netlify-адрес → у всех, кто уже установил приложение, обновится
автоматически при следующем открытии.
